## Development

本專案為純 HTML / CSS / JavaScript 寫成的單一檔案(`index.html`),**沒有 build 步驟**,不需要安裝任何套件或依賴。

### 本機執行

1. Clone 這個 repo:
   ```
   git clone https://github.com/eric-123456/moon-festival-homework.git
   ```
2. 打開 `index.html`:
   - 最簡單:直接用瀏覽器雙擊打開檔案。
   - 建議方式:在 VS Code 安裝「Live Server」擴充套件,右鍵 `index.html` → *Open with Live Server*,存檔會自動重新整理。

### 部署

推上 GitHub 後,在 repo 的 **Settings → Pages** 設定 Source 為 `main` 分支、`/ (root)` 資料夾即可,GitHub 會自動發布成公開網址。
